- **Document themes.** A workspace makes its own document themes: the print colour, whether headings take it too, and the letterhead's logo and lines. Every document prints in Whity's standard theme, the workspace's default, the default for its kind, or one it names, and can override the print colour and letterhead itself. The editor's page view and the PDF use the same resolved theme. Publishing a template keeps the theme it was published with, so a theme changed later reaches it only when it is published again. `/api/document-themes` lists, shows, resolves and manages them, and the routes are MCP tools in the `core.documents.themes` toolset (WHIT-735, WHIT-737).
- **New permission `documents:themes`** to manage the workspace's themes and choose its default theme. Migration 172 grants it to every role that holds `documents:publish` (WHIT-735).
