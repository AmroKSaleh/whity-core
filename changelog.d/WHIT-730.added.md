- **One issuing service.** Every way of issuing a document (the editor, `POST /api/documents`, the editor's render route with `persist`, and plugins) goes through it, so every issued document records its template and version and gets its QR code. An `origin_key` names what a document is (for example `order:4812:invoice`): issuing again with it returns the first document instead of a second one. A value given with the request can fill a template's own fields and any field the record left empty, never one the record resolved (WHIT-730, WHIT-741).
- **Document events (plugin SDK 1.49).** `document.issuing` (a listener may refuse with `HookVetoException`), `document.issued` and `document.rendered`, with `.async` forms. They carry ids, never field values (WHIT-730).
