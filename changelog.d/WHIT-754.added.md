- **MCP admin: plugin always-on tools, agent credentials and list sizes.** A plugin tool that asks to be always-on is now listed directly to MCP clients only once a workspace admin turns it on (new setting `mcp.always_on_plugin_tools`), and only while the bare list stays within its budget (12 tools, 10 KB). `POST /api/mcp/tokens` takes `agent: true` to issue an agent credential: an AI that works for you unattended, under your permissions narrowed by its `grant:` entries, whose Ask-first calls become proposals you approve. A person's own token can't carry grants. `GET /api/v1/admin/mcp/tools` now shows each tool's toolset, visibility and agent policy, includes plugin-authored tools, marks which plugin always-on requests are on, and estimates what each list mode costs a client (WHIT-754).
