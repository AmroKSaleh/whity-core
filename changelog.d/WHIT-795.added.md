- **Workspace plugin automations can issue documents (plugin SDK 1.57).** An automation step can issue a document from one of the plugin's template slots for the record that triggered it, such as "when an order is confirmed, issue its confirmation". It uses the template the workspace bound to the slot, and fills the template's own fields from the record. It acts as the person who caused the change, who needs permission to issue documents. A retried run never issues a second document. A refusal (no template bound, missing fields, a vetoed issue) stops the run, with the reason in its trace (WHIT-795).
