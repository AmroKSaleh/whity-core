- **Plugin SDK 1.56: documents for code plugins.** The optional `PluginDocumentsInterface` declares template slots (`Documents\TemplateSlot`, addressed as `<plugin name>.<slot>`) and the plugin's record types as merge fields (`Documents\DocumentFieldProvider`, `<plugin name>.<type>`); a bad declaration is dropped with a logged reason. The host service `Documents` (`\Whity\app(Documents::class)`) issues from a slot or a template for a record, as the person whose request it is, and refuses with `DocumentNotIssuedException` and a stable reason (`no_actor` outside a request). `plugins/HelloWorld` declares a greeting-card slot as the worked example. See `docs/wiki/Plugin-Development.md`, step 12b (WHIT-742).
