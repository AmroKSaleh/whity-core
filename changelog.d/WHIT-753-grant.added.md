- **MCP: an agent's scope grant, per permission.** An agent credential's scope can say, for each permission, whether the agent may use it: Off, Ask first or Allowed (`grant:invoices:send=allow`). Without an entry, reads the person holds are Allowed and everything else is Ask first. A route's `agentPolicy` and the lack of an undo can only lower that. An agent sees each operation's mode in `tools/list` and does not see what is Off. Ask first is refused until agent proposals exist, and no agent credentials are issued until then; people's own clients are unaffected (WHIT-753).
