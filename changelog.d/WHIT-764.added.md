- **Publish and roll back a workspace's own plugins through the API.** `/api/v1/workspace-plugins` lists a workspace's plugins and can validate a manifest. It can also show what publishing it would change, with each change marked safe, needing attention, or destructive, and the number of existing records it touches. Publishing a destructive change has to be confirmed. Every version is kept, so any earlier one can be made live again, and nothing is deleted from the records. Two new permissions, `plugins:build` and `plugins:publish`, separate drafting a change from putting it live. Both are granted to roles that can already enable plugins (WHIT-764).
