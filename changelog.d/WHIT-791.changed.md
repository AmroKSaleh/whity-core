- **Changelog entries are now one file per pull request.** Add `changelog.d/<id>.<section>.md` (for example `WHIT-789.added.md`) instead of editing `CHANGELOG.md`, so parallel pull requests no longer conflict on the shared [Unreleased] section and drop out of the merge queue. `release-prepare.yml` folds the fragments into [Unreleased] when it prepares a release, and CI checks every fragment's name and content. Entries already in [Unreleased] are kept (WHIT-791).
