- **One search across Whity: `GET /api/search`.** It finds documents, forms, people and organisational units, and plugin records whose data type opts in with a `search` key. Each type is searched only when you can list it, with the same per-record rules as its list, so nothing from another tenant or a type you can't see appears. Arabic spellings match loosely: أ/إ/آ match ا, ة matches ه, ى matches ي, and harakat and tatweel are ignored. It is also the MCP "search records" tool (`get_api_search`), one of the five always-on tools, in a new `core.search` toolset. `GET /api/search/types` lists what you can search (WHIT-783).
