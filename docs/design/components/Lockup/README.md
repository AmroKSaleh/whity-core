# Lockup

The mark with the “Whity” wordmark (Readex Pro SemiBold, drawn as outlines). Horizontal is the default; stacked is for square spaces such as splash screens and social avatars.

**Props:** `height` (the mark height in px; the wordmark scales with it), `layout` (`horizontal` · `stacked`), `tone` (`auto` · `onbrand`).

The word's cap height equals the platform's side and its cap line and baseline are the platform's top and bottom edges; the gap is 3 m (decision 1.6a). Keep a quarter of the mark height clear on every side (`logo-clear-space`, 3 m). Minimum heights: 20px for the horizontal lockup (`logo-min-horizontal`), 48px for the stacked one (`logo-min-stacked`). The lockup is the same in every language and never mirrors. Never set “Whity” in live type next to the mark.
