# App shell: mobile

Under 768px (or with `mobile`) the sidebar leaves the layout. A menu button at the start of the top bar opens it as a drawer over a scrim, 85% of the width at most, from the start edge: the left in English, the right in Arabic. The page gets 16px gutters (4.5) and the search loses its shortcut hint. Touch targets stay at least 44px tall in the tenant apps.
