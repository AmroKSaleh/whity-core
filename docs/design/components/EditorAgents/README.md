# Agents in the editor

How agents write in documents (part 7). Everything an agent writes is a suggestion: dashed, attributed, nothing lands until a person accepts (E.4).

- **Asking:** from the / menu (Ask an agent), the toolbar, the bubble (Rewrite), or by @mentioning an agent in a comment, where it replies in the thread and any change arrives as a suggestion (E.30). The prompt sheet is dashed: an agent picker (the agents this person may use), context chips (this document and the records its fields and blocks point to, within the agent's and the person's permissions, E.31), the request, the permission it will use and who it acts for, and Ask.
- **Writing:** the sheet shows the run in place with `AgentRunStatus` ("Reading 3 overdue invoices") and Stop; text streams in as it's written.
- **Result:** the suggested blocks stay dashed with the actor chip, the time, and Accept, Reject, Try again and Change the request. Merge fields the agent uses are real fields. Accepting sets them down as ordinary blocks (the 200ms set-down from 2.6).
- **Rewrite:** the selection is struck through and the agent's version follows as a dashed insertion, with a rail card saying what it did ("friendlier, same meaning").
- **Agent comments:** an agent can comment like a person and offer a fix ("Suggest the fix" turns it into a suggestion).
- **Unprompted:** agents suggest only when asked or on a routine an owner set up ("check templates against new tax rules monthly"), always as suggestions (E.32).
- **Accounting:** the actor chip, the person it acts for and the permission it used appear on every card, in the document history and in the audit log; printed documents an agent made or sent say so in the footer.
