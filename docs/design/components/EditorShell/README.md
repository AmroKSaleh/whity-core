# Editor shell

The frame every document opens in (decisions E.5–E.7). From the top:

- **Header (56px):** back to where the document lives, its icon on the tint, the title (click to rename), the path and the save state ("Saved 14:02", "Saving…", "Offline, changes kept on this device"). At the end: the mode menu (Editing, Suggesting, Viewing; people who can't edit get Suggesting, E.10), comments with a count, PDF (Whity Render), and the one main action on the plane: **Publish** for templates, which turns the draft into the version Whity Render and agents use (E.9). Notes and wiki pages save live and have no main action.
- **Toolbar (44px):** Google Docs order, groups divided by hairlines: undo and redo · style (Normal text, Heading 1–3) · bold, italic, underline, strikethrough · link, highlight · bulleted, numbered, checklist · Insert ▾ · Field ▾ · comment · **Ask an agent** (dashed, since what it writes is a suggestion) · then view (continuous or page), zoom in page view, outline. Every icon button has a tooltip with its shortcut; pressed states use the tint. Under 768px the toolbar scrolls sideways and the bubble and / menu carry the rest.
- **Body:** the outline (220px, headings, the current one marked in the main colour), the canvas on the grey ground, and the margin rail (300px) with comment and suggestion cards beside what they belong to (E.6). Under 1280px the outline closes; under 1024px the rail becomes a drawer opened from the comment count.
- **Status bar (28px):** words, language, document type, pages in page view, and who edited last.

The continuous sheet is one sheet on the grey ground (white in light mode, the card colour in dark mode, E.11), 760px wide with 72px sides: the title in Readex Pro 600 (a document title, decision 3.1), then the blocks. Templates open in the page view instead (E.7).
