# DocPreview

How a document from Whity Render shows inside the app: the document's name and key facts, its status (draft, issued, accepted by JoFotara), zoom, Print, Download PDF and Send (the one main action). The page sits on a grey canvas at real proportions, the same `Doc` that prints, so what you see is what the customer gets. In the app it opens from a record's Documents tab or after Issue.
