# ActorChip

Names who did something. A person: initials, solid border. An agent (an AI principal): the robot face on the tint, a dashed border, and the person it acts for, because an agent never holds more permission than the person who granted it. The system: the mark. Shape and words carry the difference, never colour alone. **Props:** `kind`, `name`, `onBehalfOf`, `forLabel`.
