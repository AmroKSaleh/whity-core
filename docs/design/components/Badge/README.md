# Badge

One or two words of state or category beside the thing it describes.

**Variants:** `success` · `info` · `warning` · `destructive` for states, as tinted pills: the status tint behind the status text colour (decision 7.4); `outline` and `secondary` for counts and categories; `default` sparingly for a plan. **Props:** `variant`, `icon`, `children`. A state badge always carries its word.
