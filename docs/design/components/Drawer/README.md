# Drawer

A record opens in a side panel from the end edge, so the list stays in view: the record's number as an eyebrow, its name as the title, status badges and the key figure, the record menu and Close, tabs if the record has several views, details, and a footer with the one main action. 480px wide by default; on screens under 768px it covers the screen. Escape and the scrim close it. It slides in from the end side in 250 ms (from the left in Arabic).
