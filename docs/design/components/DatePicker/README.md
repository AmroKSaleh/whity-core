# DatePicker

One date or a range. The week starts on Saturday and Friday and Saturday are greyed as the weekend, as in Jordan (`weekStart`, `weekend` change this). Arabic uses the Levantine month names (تشرين الأول) with Western digits (3.7b). Today has a ring; the selected day is the main colour and a range between is the tint (7.3). Ranges offer quick picks and show the number of days under the field.

Dates display as "27 Oct 2026" in English and "27 تشرين الأول 2026" in Arabic (`Whity.formatDate`); the value is a plain date with no time zone.
