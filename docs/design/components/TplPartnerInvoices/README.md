# Partner app: invoices

A partner's product built on Whity: the tenant's logo and colour lead (`.wy-theme-partner` overrides only the white-label tokens), Whity appears once, as the optional Built on Whity credit at the sidebar foot. Invoices show payment and JoFotara status as separate badges, each with a word. Issuing is blocked, not hidden, when a tax number is missing. Example names throughout are fictional.

Needs: Whity Front Office (proposed app) and a JoFotara integration; statuses shown are illustrative until the integration is specified.
