# Blueprint

The technical drawing style: Whity Blue ground (`blueprint`), a 16px fine grid and 80px major grid in white (`blueprint-line`, `blueprint-line-strong`), mono labels like a drawing sheet. It does not invert with the theme.

**Use only** to explain how the platform works: architecture, tenancy, the plugin boundary, the agent surface, request flow. Never for pricing, policy, marketing claims or a tenant's own pages.

**Props:** `label` (mono sheet label), `title`, `children` (draw boxes with white 1.5px lines; dashed lines for things that have not happened yet).
