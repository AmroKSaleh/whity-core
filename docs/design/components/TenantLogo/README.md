# TenantLogo

The slot where a tenant's own brand appears: in the sidebar, the tenant switcher, sign-in, emails and documents. An uploaded logo sits in a framed square; without one, the initials sit on the tenant's main colour (one letter below 32px, two from 32px). Corners are 29% of the size, the same as the app's tiles. `showName: false` keeps only the mark and moves the name to its accessible label.
