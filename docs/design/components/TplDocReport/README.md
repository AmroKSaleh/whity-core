# Report (multi-page)

A monthly sales report that prints well: a three-line summary first, four key numbers, one chart, then tables, with notes on page 2 and a note on how it was made. Key numbers and totals are in ink and bold only where they matter.

Charts on paper follow the document colour rule (tenant colour on the title only): grey bars with the one that matters in ink, values written on the bars, light gridlines, no legend. They stay readable in black and white and on a fax. On screen, reports use the chart palette instead.

Built from `DocPages` (one body per page, the same letterhead, running header and foot), `DocKpis`, `DocBars`, `DocTable`, `DocNote`. Figures are example data that agree with the other templates (overdue JOD 429.500).
