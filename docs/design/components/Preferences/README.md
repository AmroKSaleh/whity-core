# LanguageSwitch and ThemeSwitch

Two segmented controls for the user menu, the account settings and sign-in. Language shows each name in its own language and script (English, العربية); switching mirrors the layout. Theme is Light, Dark or Auto (follows the device); the compact form shows icons with tooltips. The selected option is tinted (7.3). Both are built on `Segmented`, which is available for other short either/or choices.
