# Branding (white-label)

Where a tenant or partner makes Whity theirs: product name, domain, logo, main colour. The preview re-themes live with `Whity.tenantTheme(colour, mode)`, the white-label contract (decision 2.8): the label on the colour is white or near-black, whichever reaches 4.5:1; the tint (L 0.96), the colour on dark (L 0.70) and the plane (L 0.30) are derived from its hue. Greys and status colours never change. Built from `AppShell`, `PageHeader`, `Card`, `Input`, `Switch`, `Tabs`, `Button`, `BuiltOnWhity`. Matches `admin/settings/branding` in whity-core.
