# Sign in

The same sign-in page twice: as Whity's own console (the lockup, Whity Blue) and as a tenant's product (their logo and colour through `.wy-theme-partner`, with the optional Built on Whity credit at the foot). Only the logo slot, the product name and the white-label tokens change.

Order: Google (SSO) first when the tenant enables it, then email and password. “Forgot password?” sits beside the password label. The main button is the only `default` button. The language switch names each language in its own script. Built from `Lockup`, `Button`, `Input`, `BuiltOnWhity`. Matches `/login`.
