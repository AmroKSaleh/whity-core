# Inserting

Every way in to a new block (part 5).

- **The / menu** (Notion): typing / at the start of a line, or after a space, opens every block grouped: Basic, Lists, Media, Structure, Whity (Record, Chart, Signature and stamp), **Saved blocks** (E.21), one group **per plugin** with its logo (E.20), and **Ask an agent** last (dashed, like every agent row, decision 2.1c). Each row has an icon tile, a name, a one-line hint and its Markdown shortcut.
- **Filtering:** what's typed after / filters by name, hint and keywords (/tab → Table). Enter on an empty line turns it into the block; on a line with text it inserts the block after. Esc closes and keeps what was typed.
- **The + inserter** (Gutenberg): the + in the gutter opens the same menu with a search box and inserts below that block.
- **Empty line hint:** the focused empty line reads "Type / for blocks, {{ for fields, or just write"; other empty lines stay blank.
- **Markdown shortcuts:** # ## ### for headings, - or * for bullets, 1. for numbers, [] for a checklist, > for a quote, ``` for code, --- for a divider, **bold**, _italic_, `code`, {{ for a field. ⌘Z straight after turns it back into the typed text.
- **Paste:** text pastes as text; a list of lines becomes paragraphs or list items; a link pasted on a selection makes a link; a link to a Whity record offers "Show as a record block".
