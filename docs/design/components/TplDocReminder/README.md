# Payment reminder

A polite, plain reminder: a short letter first (if you've paid, ignore this; if not, pay by a date; call if something looks wrong), then only the overdue invoices with how many days late, the total with the amount in words, how to pay, and a QR that opens the payment page.

This is the reminder the Billing assistant asked to send in the Approvals template. The footer says so: an agent sent it for a named person, with her approval. Nothing goes out unattributed. Built from `Doc` (`intro`), `DocNote`.
