# Quote

The first document in the sales cycle. Same letterhead and line table as the tax invoice, with what a quote needs instead of tax fields: who it is prepared for, how long it is valid, when and where it is delivered, the terms, and an acceptance row (accepted by, signature, date). There is no JoFotara stamp, because a quote is not a tax document. The QR opens the quote online, where the customer can accept it; accepting turns it into invoice INV-1042.

Built from `Doc`, `DocNote` and `DocSign`. Terms and dates are example data.
