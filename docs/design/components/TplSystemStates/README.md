# System states

Every error and pause says what happened, that nothing was lost when that is true, and the one thing to do next. The art is the mark's two planes with the sheet dashed: not set down. No illustrations of broken robots or jokes. Codes are small mono labels; the title carries the meaning. A 500 always gives a reference to copy. Matches whity-core's 404, 403, 500, rate-limit and status pages.
