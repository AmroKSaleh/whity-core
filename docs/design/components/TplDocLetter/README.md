# Letter

A business letter on the tenant's letterhead. With no title, the end of the header carries only the reference and date. Then the recipient, a bold subject line, the body at 9.5 pt with 1.6 line spacing, the sign-off and a signature row, and enclosures. Plain words, one idea per paragraph, the ask in the last paragraph.

Built from `DocPages`, `DocSign`. Arabic-led letters work the same way (see Employment letter).
