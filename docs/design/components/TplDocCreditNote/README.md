# Credit note

Reduces an invoice that has already been issued (in JoFotara terms, a return invoice). It names the original invoice and its amount, says why, lists only the returned or corrected lines, and ends with the credit total and the amount in words. It goes through JoFotara like the invoice, so it carries the stamp, reference and QR.

Here one large tray from INV-1042 came back damaged: JOD 98.600 credited, leaving JOD 203.000 due. Built from `Doc` and `DocNote`.
