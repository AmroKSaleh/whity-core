# BuiltOnWhity

The credit a partner or tenant may show: the mono small-cut mark and “Built on Whity”, linking to whity.dev.

**Use** in footers, About screens and the sidebar foot of a white-labelled app, never in a header and never larger than the partner's own logo. Optional for partners; never required.

**Props:** `href` (default https://whity.dev), `label` (translated text; the name “Whity” stays in Latin letters).

Static files: `built-on-whity-light.svg`, `built-on-whity-dark.svg` in Logos.
