# Payslip

One line per pay item, with earnings and deductions in their own columns so each total is easy to check, then net pay in bold with the amount in words in both languages, and the leave balance beside the totals (`aside`). Marked confidential; the QR lets a bank or landlord check it is genuine without calling HR.

Example figures (JOD 943.610 net): the social security share and tax are illustrative; payroll rules come from the HR app's settings. The leave balance matches the Leave approval template. Built from `Doc` and `DocTable`.
