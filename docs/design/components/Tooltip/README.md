# Tooltip

A short label in ink that appears after half a second on hover and at once on keyboard focus. Every `IconButton` gets one from its `label`, which is also its accessible name, so it is not read twice. A tooltip can carry a keyboard shortcut. Tooltips name things; they never hold information that is needed to finish a task (put that in helper text).

`IconButton` now also has `size: 'sm'` (28px) for tables and toolbars.
