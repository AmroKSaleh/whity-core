# Employment letter (Arabic leads)

A "to whom it may concern" letter confirming someone's job, start date and salary, for a bank, landlord or embassy. In Arabic, because most of these go to Jordanian institutions; the labels carry small English. The salary is written in figures and in words. The QR lets the receiving institution check the letter is genuine, which replaces the phone call to HR.

Built from `DocPages` (free-form body under the same letterhead and foot), `DocSign`. Wording is an example; HR sets the template text.
