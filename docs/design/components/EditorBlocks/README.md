# Blocks

Everything in a document is a block (decision E.2). One catalogue serves templates, letters, reports, notes and wiki pages; the page view prints the same blocks with the stage 6 rules (hairline tables, ink only, the tenant colour on the title).

| Group | Blocks |
| --- | --- |
| Text | Text · Heading 1, 2, 3 · Quote · Code |
| Lists | Bulleted · Numbered · Checklist (nest with Tab, up to 3 levels) |
| Callouts | Note (grey) · Important (warning tint) |
| Structure | Toggle (holds blocks) · Columns (2) · Divider · Page break |
| Media | Table · Image (half, wide, full; caption) · File |
| Whity | Record (a live invoice, customer or any record) · Chart (live) · Signature and stamp |

Inline, inside any text: bold, italic, underline, strikethrough, code, link, highlight, merge fields, comments and suggestions (parts 4 and 6).

Rules: headings are Noto Sans 600 (the title alone is Readex Pro); lists use the muted marker colour; tables are plain document tables (header row, end-aligned numbers), not data tables; a record or chart block shows live values in the editor and the values at the moment of rendering in each PDF.
