# Block chrome

How a block is added, moved and changed (decision E.8).

- **Gutter:** hovering a block (or putting the caret in it) shows two buttons in the margin at its first line: **+** opens the inserter for a new block below, the **handle** drags the block or, clicked, opens its menu. The gutter sits in the sheet's side padding, or the page margin in the page view, so text never moves.
- **Block menu:** Turn into (the text types), Comment, Duplicate, Copy link to block, Move up, Move down, Delete, each with its shortcut. Keyboard: Esc then Enter on a block opens it.
- **Dragging:** the block fades in place, a lifted copy follows the pointer, and a 2px line in the main colour shows where it will land, between blocks or inside a toggle or column. Keyboard: ⌥⇧↑/↓ moves the current block.
- **Selected rich block:** clicking a table, image, callout, record, chart, file or signature selects it (a 2px focus ring) and shows its toolbar above it (Gutenberg): image width, caption, alt text, replace; table header row, add row and column (also from the + on its edges); callout type; record or chart source. Backspace deletes a selected block; Enter edits inside it.
- Agents can't drag or delete: what they change arrives as a suggestion (E.4).
