# Statement of account

Everything that moved on one customer's account in a period: the opening balance, each invoice (debit), receipt and credit note (credit), and the balance after each line, then the period's debits and credits, the balance due with the amount in words, and an ageing table that shows how old the balance is.

Here Example Clinic's October: INV-1042, credit note CN-0012 and receipt RCT-0207 from the Sales set appear in order, leaving JOD 281.000. Built from `Doc` and `DocTable`. Not a tax document: no stamp or QR.
