# Two-step verification

Three moments: entering the 6-digit code at sign-in (digits in Geist Mono, grouped 3–3, “Trust this browser for 30 days”, a recovery-code way out), turning it on (QR and a typed key), and saving recovery codes (download before continuing). Matches whity-core's TOTP two-step with encrypted secrets and recovery codes. The QR here is an example.
