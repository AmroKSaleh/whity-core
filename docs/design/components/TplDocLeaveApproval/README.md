# Leave approval

The approved request as a document the employee can keep: the dates and working days (Sunday to Thursday), who covers, the balance before and after, and the approval trail. The trail shows who did what, including the HR agent that checked the balance and acted for a named person, because nothing happens unseen. No signature: the approval happened in Whity and the QR checks it.

Built from `Doc` and `DocTable`. Balances match the Payslip template.
