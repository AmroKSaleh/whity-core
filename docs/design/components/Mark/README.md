# Mark

The mark: a white sheet resting on a blue platform, offset up and to the right. It picks its cut from `size` (decision 1.7a): the **master** from 24px, a **20px** cut (14/5/2/3.5 on its grid) and a **16px** cut (11/4/2/3), each pixel-fitted with a heavier edge.

**Props:** `size` (px, default 32), `cut` (`main` · `c20` · `c16`, overrides the automatic choice), `tone` (`auto` follows the theme with `brand` and `mark-sheet`; `onbrand` on Whity Blue grounds; `mono` one colour in `currentColor`), `label` (accessible name, default “Whity”).

Use the mark alone once the name is already on screen (app bars, favicons, avatars). Never below 16px. Never rotate, mirror, stretch or recolour it; the sheet is always white.
