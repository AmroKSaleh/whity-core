# Data table: selection and bulk actions

The stage 7 table: 44px rows, a sticky header (`sticky`, `maxHeight`), sort by clicking a header (arrow shows the direction; `aria-sort` is set), a checkbox column whose header selects all (mixed when some are), selected rows tinted (7.3), the row menu at the end, and a totals row for money columns. When rows are selected a dark bar rises at the foot with the count, the money total of the selection, the bulk actions and Clear (7.6). A click on the row (outside its controls) opens it, normally in a Drawer.
