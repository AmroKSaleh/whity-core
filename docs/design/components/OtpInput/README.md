# OtpInput

Six boxes for a one-time code (two-step sign-in, confirming a phone). Typing moves to the next box, Backspace goes back, and pasting a whole code fills every box. The first box asks the browser for SMS autofill (`one-time-code`). Digits only, Arabic-Indic digits accepted, always left to right, split 3 + 3 for reading. Errors say what to do next.
