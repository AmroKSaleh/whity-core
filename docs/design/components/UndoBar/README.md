# UndoBar

After the 10-second toast, Undo stays on the activity item for as long as the tool allows (for example 30 minutes for an email that has not left the outbox yet). The bar says what happened and how long is left, with a thin meter; once undone it turns dashed and says by whom (an undone action is loose again, like a proposal); when the window closes it says it can no longer be undone. Each MCP tool declares its own undo window.
