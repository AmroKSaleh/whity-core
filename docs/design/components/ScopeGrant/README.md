# ScopeGrant

What an AI principal may see and do, per `resource:action` permission: Off, Ask first, Allowed. “Ask first” routes the action through `ActionProposal` and is marked with the dashed outline. Destructive or irreversible actions default to Off. The note states the hard rule: an agent never exceeds the person who granted it (delegations work the same way). **Props:** `agent`, `onBehalfOf`, `grants`, `onChange`, `labels`.
